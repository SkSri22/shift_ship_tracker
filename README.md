# SwiftShip Tracker

## Project Overview
SwiftShip Tracker is a Salesforce-based parcel management CRM designed to manage parcel bookings, sender and receiver details, shipment tracking, and delivery operations.

This project is being developed as part of the SmartBridge capstone project.

## Objectives
- Manage parcel, sender, receiver, and delivery records.
- Track parcel progress from booking through delivery.
- Automate supported parcel operations using Salesforce Flow.
- Integrate Agentforce AI to assist with parcel-tracking queries.
- Support reporting and secure access to parcel information.

## Technology Stack
- Salesforce CRM
- Salesforce Custom Objects and Fields
- Salesforce Flow Builder
- Salesforce Prompt Builder and Agentforce
- GitHub

## Data Model
- `Parcel__c` — parcel information
- `Sender__c` — sender information
- `Receiver__c` — receiver information
- `Delivery__c` — delivery tracking information

## Planned Features
- Parcel booking and tracking
- Sender and receiver management
- Delivery status updates
- Flow automation
- AI-assisted parcel queries
- Reports and dashboards
- Role-based access control
